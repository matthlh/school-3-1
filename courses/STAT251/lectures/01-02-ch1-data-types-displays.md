## Clarifications
- **"or whatever it's called":** the full split is **categorical** (nominal / ordinal) vs **numerical** (discrete / continuous). Discrete = countable values, usually counts. Continuous = any value in an interval, usually measurements.
- **Dot plot:** numerical data, one dot per observation stacked over its value. Wins for small n with few distinct values because nothing gets binned away. A bar chart is for categories, so it isn't the comparison; the histogram is.
- **Stem-and-leaf:** a histogram you can read the raw values back out of — shape plus exact median/min/max in one hand-drawn picture. Small n only.
